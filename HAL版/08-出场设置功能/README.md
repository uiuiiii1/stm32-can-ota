# 08-出场设置功能——出厂/串口备份升级程序

接收板 0x08004000 区的"逃生舱"。当 app 区固件损坏、或 CAN 升级链路不可用时，它是**不经 CAN、纯串口**的备用升级通道。

## 进入方式

接收板复位后 3 秒内（07 bootloader 的按键窗口）**长按 PB12 ≥2 秒** → 07 写入 BOOT_RESET 标志并跳转到本程序（0x08004000）。

## 功能

- LED 闪烁指示运行中；
- **串口升级通道**（USART1 9600 8N1，DMA 双缓冲接收）：

```
发送:  start:<长度>      ← 如 start:3884
发送:  <.bin 裸文件>      ← DMA 双缓冲接收
自动:  写入 0x08008000 app 区 → 校验 → 跳转运行
```

即：**用串口就能把 app 区的固件整个换掉**，不依赖 CAN 和网关。

## 编译烧录

- Keil 打开 `MDK-ARM/template.uvprojx` → Rebuild → LOAD（ST-Link）
- 烧录位置：0x08004000（出厂程序区，与 07/09-app 共存于同一颗芯片）

## 依赖硬件

USART1（PA9/PA10，9600，DMA 双缓冲）、LED；app 区升级目标为 0x08008000（32KB）
