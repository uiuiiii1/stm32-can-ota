# 01-LED1——示例升级对象 app

最小化的演示程序（链接基址 0x08008000）：PA0 LED 每 1 秒翻转一次，仅此而已。

它的作用是给 OTA 链路当"活体靶子"：

- 烧在接收板上时，它是"旧版本"；
- 用本仓库的网关把它经 CAN 推送到接收板后，07 bootloader 搬运跳转，板上运行的程序就从"旧版本"变成了这个 1 秒闪灯程序——**LED 行为的变化就是升级成功的最直观证明**。

想换成自己的程序：任意工程把链接基址设为 0x08008000（同时 `SCB->VTOR=0x08008000`）生成 .bin，走一遍"网关入库 → 按键触发 → 复位跳转"即可。

## 编译烧录

- Keil 打开 `MDK-ARM/01-LED1.uvprojx` → Rebuild → LOAD（注意：若直接 LOAD 到接收板，会覆盖 0x08008000 处的当前 app）
- 正常部署方式是把它作为 .bin 经 OTA 链路安装（见仓库根 README 的使用流程）

## 依赖硬件

LED PA0（或 PA0~PA2）
